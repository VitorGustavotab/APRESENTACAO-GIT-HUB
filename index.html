01 · conceito

O que é o GitHub?

O GitHub é uma plataforma online para hospedar e gerenciar projetos de código. Ele guarda o histórico completo de cada projeto, permitindo que qualquer alteração seja registrada, revisada e recuperada quando necessário.

Mais do que um repositório de arquivos, é o lugar onde equipes se encontram para organizar, discutir e evoluir o mesmo projeto juntas.

02 · utilidade

Para que ele é usado?

Quatro motivos que fazem do GitHub o ponto de encontro de quem programa.

Histórico completo

Cada alteração fica registrada. É possível voltar a qualquer ponto do histórico do projeto sem perder nada pelo caminho.

Colaboração

Vários desenvolvedores trabalham no mesmo projeto ao mesmo tempo, sem sobrescrever o trabalho uns dos outros.

Portfólio

Seu perfil público mostra os projetos em que você trabalhou — é o currículo prático de quem programa.

Comunidade open source

Milhões de projetos abertos recebem contribuições de qualquer pessoa — de quem está começando a grandes bibliotecas usadas no mundo todo.

05 · na prática

GitHub no dia a dia

Exemplos reais de uso — do sistema que roda no seu celular ao trabalho da faculdade.

🐧

O kernel do Linux

O código-fonte do Linux — base de servidores, do Android e de incontáveis dispositivos — é mantido publicamente no GitHub, recebendo contribuições de milhares de desenvolvedores.

github.com/torvalds/linux
⌨

Editores e ferramentas

O Visual Studio Code é desenvolvido abertamente: quando um usuário encontra um bug, ele abre uma issue e o time responde ali mesmo, à vista de todos.

github.com/microsoft/vscode
🌐

Hospedar sites de graça

O GitHub Pages publica um site direto do repositório, sem servidor nem custo. O simulador de Git Bash que vimos há dois slides está hospedado exatamente assim.

gaelaleixo.github.io/GitBash
⚙

Automação (Actions)

A cada envio de código, o GitHub Actions roda testes e publica a nova versão sozinho — o time descobre um erro em minutos, não depois que o usuário reclama.

docs.github.com · GitHub Actions
🏛

Dados abertos do governo

Órgãos públicos brasileiros publicam catálogos e códigos no GitHub, e qualquer cidadão pode sugerir correções abrindo um pull request.

github.com/dadosgovbr
🎓

Trabalhos da faculdade

Projetos em grupo ficam versionados: cada integrante trabalha em sua parte, o histórico mostra quem fez o quê, e o perfil vira portfólio na hora do estágio.

github.com/<seu-usuario>
